# color_inverter
basically i use compliment of each color picel (255-r, 255-g, 255-b)
where :=
r: Red
g: Green
b: Blue

## How to run it
```bash
python script.py <input_image> [output_image]
```
here output image will be as same as name in [output_image]
or
```bash
python script.py <input_image>
```
output image will be name of input_image_inverted
